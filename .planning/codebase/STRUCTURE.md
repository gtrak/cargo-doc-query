# Codebase Structure

**Analysis Date:** 2026-02-12

## Directory Layout

```
cargo-doc-query/
├── .planning/           # Planning documents and GSD workflows
│   └── codebase/        # Architecture and structure docs
├── .opencode/           # Opencode agent configuration
├── src/                 # Source code
│   └── main.rs          # Entry point (currently stub)
├── Cargo.toml           # Package manifest
├── .gitignore           # Git ignore rules
└── plan.md              # Product requirements document
```

## Directory Purposes

**src/:**
- Purpose: Rust source code
- Contains: `.rs` files for all modules
- Key files: `main.rs` (entry point)
- Planned structure:
  - `src/main.rs` - CLI entry and argument parsing
  - `src/commands/` - Subcommand implementations
  - `src/index/` - Graph data structures
  - `src/parser/` - rustdoc JSON parsing
  - `src/cache/` - Cache management

**.planning/:**
- Purpose: GSD planning documents
- Contains: Architecture docs, workflows
- Key files: `codebase/ARCHITECTURE.md`, `codebase/STRUCTURE.md`

**.opencode/:**
- Purpose: Opencode agent configuration
- Contains: Agent definitions, protocols, skills
- Note: Generated by opencode init

## Key File Locations

**Entry Points:**
- `src/main.rs`: Application entry point

**Configuration:**
- `Cargo.toml`: Package name, version, dependencies
- `.gitignore`: Excludes `/target`

**Core Logic:**
- Currently in `src/main.rs` (stub only)
- Planned modules per `plan.md` architecture section

**Documentation:**
- `plan.md`: Full PRD with technical specifications
- `.planning/codebase/*.md`: Architecture documentation

**Testing:**
- Not yet established
- Follow Rust convention: `src/*.rs` with `#[cfg(test)]` modules or `tests/` directory

## Naming Conventions

**Files:**
- `snake_case.rs` for module files (Rust convention)
- `mod.rs` for directory module roots

**Directories:**
- `snake_case/` for module directories

**Modules:**
- Crate-level modules in `src/`
- Submodules in `src/{module}/`

## Where to Add New Code

**New Command:**
- Primary code: `src/commands/{command_name}.rs`
- Register in: `src/commands/mod.rs`

**New Index Type:**
- Implementation: `src/index/{type_name}.rs`
- Export in: `src/index/mod.rs`

**New Parser:**
- Implementation: `src/parser/{format}.rs`
- Types in: `src/parser/types.rs`

**Shared Utilities:**
- Helpers: `src/util.rs` or `src/util/{category}.rs`

**Tests:**
- Unit tests: In-module `#[cfg(test)]` blocks
- Integration tests: `tests/{test_name}.rs`

## Special Directories

**target/:**
- Purpose: Cargo build artifacts
- Generated: Yes (by Cargo)
- Committed: No (in `.gitignore`)

**target/doc-query/ (planned):**
- Purpose: Cache directory for parsed indices
- Generated: Yes (by tool)
- Committed: No (in `.gitignore`)
- Layout:
  ```
  target/doc-query/
  ├── metadata.json
  └── crates/
      ├── serde.bin
      └── tokio.bin
  ```

**Cargo Registry Cache:**
- Purpose: Stores crate dependencies
- Location: `~/.cargo/registry/`
- Managed by: Cargo
