    Create new module `src/types/detail.rs` with the DetailLevel enum:
    
    ```rust
    /// Level of detail for metadata display
    #[derive(Debug, Clone, Copy, PartialEq, Eq)]
    pub enum DetailLevel {
        /// Minimal mode: signatures only, no metadata
        Minimal,
        /// Standard mode: signatures + visibility + generics (default)
        Standard,
        /// Detailed mode: full metadata including attributes, deprecation, function modifiers
        Detailed,
    }
    
    impl DetailLevel {
        /// Determine detail level from CLI flags
        /// - --minimal forces Minimal
        /// - --detailed forces Detailed
        /// - otherwise Standard
        pub fn from_flags(minimal: bool, detailed: bool) -> Self {
            if minimal {
                Self::Minimal
            } else if detailed {
                Self::Detailed
            } else {
                Self::Standard
            }
        }
        
        /// Check if this level should include visibility
        pub fn includes_visibility(self) -> bool {
            matches!(self, Self::Standard | Self::Detailed)
        }
        
        /// Check if this level should include generics
        pub fn includes_generics(self) -> bool {
            matches!(self, Self::Standard | Self::Detailed)
        }
        
        /// Check if this level should include attributes
        pub fn includes_attributes(self) -> bool {
            matches!(self, Self::Detailed)
        }
        
        /// Check if this level should include deprecation
        pub fn includes_deprecation(self) -> bool {
            matches!(self, Self::Detailed)
        }
        
        /// Check if this level should include function modifiers
        pub fn includes_function_modifiers(self) -> bool {
            matches!(self, Self::Detailed)
        }
    }
    ```
    
    Implement Default for DetailLevel returning Standard.
    Add comprehensive unit tests for all methods.
  </action>

  <name>Task 2: Create metadata extraction helpers</name>
  <files>src/types/detail.rs</files>
  <action>
    Add the following extraction helper functions to src/types/detail.rs:
    
    **1. visibility_to_string()**
    - Input: &rustdoc_types::Visibility
    - Output: String representation
    - Handle all 4 variants per RESEARCH.md:
      - Public -> "pub"
      - Default -> "" (empty string for private)
      - Crate -> "pub(crate)"
      - Restricted { path, .. } -> format!("pub(in {})", path)
    
    **2. format_generics()**
    - Input: &rustdoc_types::Generics
    - Output: Option<String> (None if empty)
    - Filter synthetic params (is_synthetic: true)
    - Format each param as "name: bound1 + bound2" for types
    - Include default values: "T = DefaultType"
    - Format where clauses: " where clause1, clause2"
    - Return format: "<K: Eq + Hash, V>" or "<T = String>"
    
    **3. extract_deprecation_info()**
    - Input: Option<&rustdoc_types::Deprecation>
    - Output: Option<(bool, Option<String>)>
    - Return None if input is None
    - Return (true, note) - skip "since" per requirements
    
    **4. extract_semantic_attrs()**
    - Input: &[rustdoc_types::Attribute]
    - Output: Vec<String>
    - Filter per requirements:
      - Attribute::MustUse { reason } -> "#[must_use]" or "#[must_use(\"reason\")]"
      - Attribute::NonExhaustive -> "#[non_exhaustive]"
      - Skip: Repr, AutomaticallyDerived, Other (except check for "deprecated")
    
    **5. extract_function_modifiers()**
    - Input: &rustdoc_types::FunctionHeader
    - Output: (bool, bool, bool, Option<String>)
    - Returns: (is_const, is_async, is_unsafe, abi_string)
    - ABI: Only return Some if not Abi::Rust
    - Handle Abi variants: C, Cdecl, Stdcall, etc.
    
    Add comprehensive unit tests using test data from RESEARCH.md.
    Test edge cases: synthetic generics, restricted visibility paths, empty generics.
  </action>
