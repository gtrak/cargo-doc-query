# Plan 05-05: Module Expansion (Above & Beyond)

**Objective:** Add module expansion capability to explore crate modules, not just types. This was NOT in the original Phase 5 requirements but adds significant value.

**Phase:** 05 - Integration & Polish
**Plan Number:** 05-05
**Status:** ✅ Complete (retroactive - above and beyond)

**Note:** This feature was not in the original roadmap but was implemented as a valuable addition during Phase 5 work.

---

## Context

Users need to explore module hierarchies within crates, not just individual types. This allows understanding crate structure and discovering modules.

This capability goes beyond the original Phase 5 requirements but fits naturally with the existing expand/query functionality.

---

## Implementation

### Tasks

#### Task 1: Module Expansion Core Logic
**Status:** ✅ Complete
**Commit:** Multiple commits

Implement module expansion in `expand.rs`:
- Accept module paths (e.g., "anyhow", "std::collections")
- List all items in the module
- Show functions with signatures
- Show types, traits, submodules
- Handle recursive expansion with --depth

**Code location:** `src/query/expand.rs`

**Verification:** Can expand modules like `anyhow` or `std::collections`.

---

#### Task 2: Module Query Support
**Status:** ✅ Complete
**Commit:** Multiple commits

Query command can target modules:
- `cargo doc-query query anyhow` - shows anyhow crate root
- `cargo doc-query query std::collections` - shows collections module
- Lists all module contents

**Code location:** `src/cli/query.rs`

**Verification:** Module queries return module contents.
