# Plan 05-04: Edge Case Handling

**Objective:** Handle edge cases gracefully with helpful error messages and automatic recovery where possible.

**Phase:** 05 - Integration & Polish
**Plan Number:** 05-04
**Status:** ✅ Complete (retroactive)

---

## Context

Production tools must handle edge cases gracefully. Users shouldn't see cryptic errors or crashes.

**Key decisions from 05-CONTEXT.md:**
- Missing cache: Auto-trigger build with clear message
- Missing type in query: Clear "type not found" error with suggestions for similar types
- Corrupt cache: Detect and auto-rebuild with warning
- Network issues: Retry once, then fail with helpful message
- Invalid Cargo.toml: Pass through cargo's error with context
- No dependencies: Friendly message explaining tool needs dependencies

---

## Implementation

### Tasks

#### Task 1: Missing Cache Auto-Build
**Status:** ✅ Complete
**Commit:** Multiple commits

Both query and expand commands detect missing cache and auto-trigger build:
- Check for cache before querying
- If missing: "No index found, building..."
- Run build automatically
- Continue with query after build completes

**Code locations:**
- `src/cli/query.rs` - lines 502-514
- `src/cli/expand.rs` - lines 109-121

**Verification:** Query without cache auto-builds and succeeds.

#### Task 2: Manifest Change Detection
**Status:** ✅ Complete
**Commit:** Multiple commits

Detect when Cargo.toml/Cargo.lock changed and auto-rebuild:

**Code locations:**
- `src/cli/query.rs` - lines 484-498
