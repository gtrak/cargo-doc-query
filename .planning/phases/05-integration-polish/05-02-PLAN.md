# Plan 05-02: Progress Indicators & Output Control

**Objective:** Add progress indicators for long operations and output control flags for different use cases (CI, piping, quiet mode).

**Phase:** 05 - Integration & Polish
**Plan Number:** 05-02
**Status:** ✅ Complete (retroactive)

---

## Context

Rustdoc JSON generation takes 2-5 seconds for typical projects. Users need visual feedback during this time, plus options to control output for different environments (CI, scripting, piping).

**Key decisions from 05-CONTEXT.md:**
- Show spinner during rustdoc JSON generation
- Display stage labels: "Generating rustdoc JSON...", "Building index..."
- Silent mode (`--quiet` or `-q`) suppresses all progress output
- Progress goes to stderr, never stdout
- Include timing info on completion
