<task type="auto">
  <name>Task 2: Add manifest change detection to query command</name>
  <files>src/cli/query.rs</files>
  <action>
Modify QueryCommand::execute() to detect manifest changes and trigger automatic rebuild before querying.

Implementation steps:
1. In query command execute(), generate current cache key from manifest files
2. Load cached index and check its stored cache_key
3. If keys differ (or no cache exists):
   - Print message: "Manifest changed, rebuilding index..."
   - Create and execute BuildCommand with default settings
   - Then reload the index from cache with new key
4. If keys match, proceed with normal query using current cached index

Key code changes:
- Import BuildCommand from crate::cli::build
- Import CacheKeyInputs from crate::cache::key
- Before creating QueryEngine, verify cache key matches
- On mismatch: run build first, then continue
- Handle build errors gracefully (return error, don't panic)

Implementation pattern:
```rust
// Before loading index, check if rebuild needed
let cache_inputs = CacheKeyInputs::from_project(&manifest_path)?;
let expected_key = cache_inputs.generate_key();

// Try to load current index and compare keys
let store = CacheStore::new()?;
if let Some(index) = store.load_current()? {
    if index.cache_key != expected_key {
        // Rebuild needed
        println!("Manifest changed, rebuilding index...");
        let build_cmd = BuildCommand::new(manifest_path, false);
        build_cmd.execute()?;
    }
} else {
    // No cache exists, need to build
    println!("No index found, building...");
    let build_cmd = BuildCommand::new(manifest_path, false);
    build_cmd.execute()?;
}
```

Add manifest_path discovery (use std::env::current_dir() + "Cargo.toml" as default).
