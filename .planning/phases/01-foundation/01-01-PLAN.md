<task type="auto">
  <name>Task 2: Create CLI entry point with clap</name>
  <files>src/main.rs</files>
  <action>
Create src/main.rs with clap derive CLI:

```rust
use clap::{Parser, Subcommand};

#[derive(Parser, Version)]
#[command(name = "cargo-doc-query")]
#[command(author = "...")]
#[command(version = "0.1.0")]
#[command(about = "Fast, structured API queries over Rust dependency documentation")]
#[command(long_about = None)]
struct Cli {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    /// Generate documentation index from Rust dependencies
    Build,
}

fn main() {
    let cli = Cli::parse();
    match &cli.command {
        Commands::Build => {
            println!("Build command invoked");
        }
    }
}
```

Use actual author string or remove the field if not needed.
  </action>
  <verify>
`cargo build --quiet 2>&1 | head -10` — No compilation errors
`cargo run -- --help 2>&1 | head -15` — Shows help with Build subcommand
  </verify>
  <done>
CLI accepts `build` subcommand, prints "Build command invoked" when run
</done>

**src/cli/build.rs:**
```rust
use anyhow::Result;
use crate::cli::Command;

pub struct BuildCommand;

impl Command for BuildCommand {
    fn execute(&self) -> Result<()> {
        println!("Build command executed");
        Ok(())
    }
}
```

Update src/main.rs to use the Command trait pattern:
```rust

}
```
