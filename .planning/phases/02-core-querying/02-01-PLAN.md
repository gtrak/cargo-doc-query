<task type="auto">
  <name>Task 2: Create query output schema types</name>
  <files>src/types/query.rs</files>
  <action>
Create src/types/query.rs with JSON output types for query responses. Use serde derive macros.

Required types:
- QueryResponse: Top-level response with query string and matches array
- QueryMatch: Individual match with crate_name, version, fully_qualified_path, kind, content
- QueryContent: Untagged enum for TypeResult or TraitResult
- TypeResult: Type query result with methods and trait_implementations arrays
- TraitResult: Trait query result with name, path, methods, associated_types, provided_methods
- MethodOutput: Method with name, signature, return_type, visibility, is_public, optional docs
- TraitImplOutput: Trait implementation with trait_name, trait_path, methods array

Example (following research Pattern 4):
```rust
use serde::Serialize;
use serde::ser::SerializeSeq;

#[derive(Serialize, Debug)]
pub struct QueryResponse {
    query: String,
    matches: Vec<QueryMatch>,
    #[serde(skip_serializing_if = "Vec::is_empty")]
    errors: Vec<String>,
}

#[derive(Serialize, Debug)]
pub struct QueryMatch {
    crate_name: String,
    version: String,
    fully_qualified_path: String,
    kind: String,  // "type", "trait", "module", etc.
    content: QueryContent,
}

#[derive(Serialize, Debug)]
#[serde(untagged)]
pub enum QueryContent {
    Type(TypeResult),
    Trait(TraitResult),
}

#[derive(Serialize, Debug)]
pub struct TypeResult {
    kind: String,  // "struct", "enum", "type alias", etc.
    methods: Vec<MethodOutput>,
    trait_implementations: Vec<TraitImplOutput>,
}

#[derive(Serialize, Debug)]
pub struct TraitResult {
    name: String,
    path: String,
    methods: Vec<MethodOutput>,
    associated_types: Vec<AssociatedTypeOutput>,
    #[serde(skip_serializing_if = "Vec::is_empty")]
    provided_methods: Vec<String>,
}

#[derive(Serialize, Debug)]
pub struct MethodOutput {
    name: String,
    signature: String,
    return_type: String,
    visibility: String,
    is_public: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    docs: Option<String>,
    #[serde(skip_serializing_if = "is_false")]
    is_trait_method: bool,
}

fn is_false(b: &bool) -> bool { !b }

#[derive(Serialize, Debug)]
pub struct AssociatedTypeOutput {
    name: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    bounds: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    default: Option<String>,
}

#[derive(Serialize, Debug)]
pub struct TraitImplOutput {
    trait_name: String,
    trait_path: String,
    methods: Vec<MethodOutput>,
    #[serde(skip_serializing_if = "Vec::is_empty")]
    provided_methods: Vec<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    generic_args: Option<String>,
}
```

Use snake_case field naming (Rust convention). Add #[serde(skip_serializing_if = ...)] for optional fields.
