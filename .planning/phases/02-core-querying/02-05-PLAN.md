# Phase 2 Success Criteria
1. User can query methods for any type (e.g., `cargo doc-query methods std::vec::Vec`)
2. Method output includes complete signature and fully qualified return types
3. User can query trait implementations for any type
4. Trait output includes associated types and all trait methods
5. All query responses are valid, parseable JSON
6. Command output can be piped to other tools (e.g., `| jq`)
</context>

<task type="checkpoint:human-verify" gate="blocking">
  <what-built>Complete query CLI with build and query commands, JSON output, and all flags</what-built>
  <how-to-verify>
**Step 1: Verify build command still works**
```bash
cargo doc-query build
```
Expected: Build completes, index cached to target/doc-query/

**Step 2: Query a type (e.g., Vec)**
```bash
cargo doc-query query std::vec::Vec
```
Expected:
- Returns valid JSON
- Output includes methods (push, pop, len, etc.)
- Output includes trait implementations (Iterator, IntoIterator, etc.)
- Each method has name, signature, return_type

**Step 3: Query a trait (e.g., Iterator)**
```bash
cargo doc-query query std::iter::Iterator
```
Expected:
- Returns valid JSON
- Output includes trait name and path
- Output includes trait methods (next, size_hint, etc.)
- Output includes associated types (Item, etc.)

**Step 4: Filter with --kind flag**
```bash
cargo doc-query query std::vec::Vec --kind methods
```
Expected: Only methods returned (no trait implementations)

**Step 5: Include docs**
```bash
cargo doc-query query std::vec::Vec --include docs
```
Expected: Output includes doc comments for methods

**Step 6: Verify JSON is parseable**
```bash
cargo doc-query query std::vec::Vec | jq .
```
Expected: jq parses JSON successfully without errors

**Step 7: Verify error on missing type**
```bash
cargo doc-query query std::nonexistent::Type
```
Expected: Error message, non-zero exit code

**Step 8: Verify error without cache**
```bash
rm -rf target/doc-query
cargo doc-query query std::vec::Vec
```
Expected: Error "No cached index found. Run 'cargo doc-query build' first."
