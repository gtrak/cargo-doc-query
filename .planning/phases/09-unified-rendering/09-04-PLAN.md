With DocHandler integration:

```rust
let docs = if self.detail_level.is_minimal() {
    None
} else {
    // Use DocHandler to extract and potentially truncate docs based on budget
    let raw_docs = item.docs.as_ref().map(|s| s.trim().to_string());
    if let Some(ref docs_text) = raw_docs {
        let handler = DocHandler::new(self.detail_level.clone(), self.token_budget);
        handler.format_docs(docs_text)
    } else {
        None
    }
};
```

This uses DocHandler::format_docs which:
- Returns None in Minimal mode (already checked above, but safe)
- Checks token_budget and calls truncate_docs when needed
- Preserves code blocks over prose during truncation
- Adds "..." indicator when truncated
