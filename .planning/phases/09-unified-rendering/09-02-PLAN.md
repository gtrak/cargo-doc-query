  <name>Create doc comment handler in src/format/doc.rs</name>
  <files>src/format/doc.rs</files>
  <action>
Create new file src/format/doc.rs with:

1. Import DetailLevel from crate::types::detail
2. Define DocHandler struct with fields: detail_level: DetailLevel, remaining_budget: Option<usize>
3. Implement DocHandler::new(detail_level, token_budget) -> Self
4. Implement extract_docs(item: &Item) -> Option<String> - gets from item.docs field, trims whitespace
5. Implement format_docs(&self, docs: &str) -> Option<String>:
   - If detail_level.is_minimal() -> return None (DOCS-03)
   - If no budget -> return Some(docs.to_string())
   - Calculate doc_tokens = docs.len() / 4
   - If would_exceed_budget(doc_tokens) -> call truncate_docs
   - Otherwise return Some(docs.to_string())
6. Implement truncate_docs(docs: &str, max_tokens: usize) -> (String, bool):
   - Calculate max_chars = max_tokens * 4
   - If docs.len() <= max_chars -> return (docs.to_string(), false)
   - Find sentence boundaries: scan for ". ", "! ", "? " before max_chars
   - Use rfind to get last complete sentence
   - Check if code blocks (```) exist before truncation point
   - If code blocks exist -> preserve them, truncate prose before code block
   - Return (truncated + "...", true) to indicate truncation
7. Implement would_exceed_budget(&self, tokens: usize) -> bool:
   - If no budget -> false
   - If remaining_budget < tokens -> true
   - Otherwise false
8. Implement sentence boundary detection:
   - Look for [.!?] followed by [space or end-of-string]
   - Return position after the punctuation

Reference existing DocExtractor from src/types/doc.rs for inspiration but implement at rendering layer per requirements.
  </action>
