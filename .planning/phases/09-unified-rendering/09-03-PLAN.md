  <name>Create BudgetTracker in src/format/budget.rs</name>
  <files>src/format/budget.rs</files>
  <action>
Create new file src/format/budget.rs with:

1. Define BudgetTracker struct with fields: 
   - total_budget: Option<usize>
   - current_tokens: usize
   - warning_threshold: f32 (default 0.8)
2. Implement BudgetTracker::new(budget: Option<usize>) -> Self
3. Implement track_item(&mut self, item_tokens: usize, doc_tokens: usize) -> (usize, TruncationAction):
   - total_item_tokens = item_tokens + doc_tokens
   - Check if would exceed budget
   - If would exceed -> return (0, TruncationAction::Truncate)
   - Otherwise -> current_tokens += total_item_tokens, return (total_item_tokens, TruncationAction::Include)
4. Implement would_exceed(&self, tokens: usize) -> bool:
   - If no budget -> false
   - current_tokens + tokens > budget -> true
   - Otherwise false
5. Implement remaining(&self) -> Option<usize>:
   - If no budget -> None
   - Some(budget - current_tokens)
6. Implement is_warning_needed(&self) -> bool:
   - If no budget -> false
   - current_tokens >= (budget * warning_threshold) -> true
   - Otherwise false
7. Define TruncationAction enum: Include, Truncate
8. Implement estimate_item_tokens(formatted: &FormattedItem) -> usize:
   - Base: 20 tokens per item (path overhead)
   - Add for each field: ~5 tokens
   - Add for each variant: ~5 tokens
   - Add for each module item: ~10 tokens
   - Add doc_tokens from FormattedItem.docs.len() / 4

This integrates budget at rendering layer per REND-04 requirement.
  </action>
  <verify>Create the file and verify: grep -n "pub fn track_item" src/format/budget.rs</verify>
  <done>BudgetTracker exists with token tracking and truncation detection</done>
