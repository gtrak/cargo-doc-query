## v1 Requirements (All Complete)

### Build System

- [x] **BUILD-01:** `cargo doc-query build` command exists and is discoverable
- [x] **BUILD-02:** Generates rustdoc JSON for all dependencies via cargo
- [x] **BUILD-03:** Index is cached to disk for sub-100ms query performance
- [x] **BUILD-04:** Index automatically rebuilds when Cargo.lock changes
- [x] **BUILD-05:** Format version checking for rustdoc JSON compatibility

### Query System

- [x] **QUERY-01:** Query methods for any type by fully qualified path
- [x] **QUERY-02:** Method output includes name, signature, and fully qualified return types
- [x] **QUERY-03:** Query responses are formatted as structured JSON
- [x] **QUERY-04:** User can limit output with token budget constraints
- [x] **QUERY-05:** User can request minimal/signature-only mode
- [x] **QUERY-06:** Recursive type expansion supports depth limits

### Trait System

- [x] **TRAIT-01:** Query trait implementations for any type
- [x] **TRAIT-02:** Trait output includes associated types and methods

### Type System

- [x] **TYPE-01:** User can expand a type recursively to see its full graph
- [x] **TYPE-02:** Expansion respects depth limits to prevent context overflow

### Output Formats

- [x] **FMT-01:** JSON output format for programmatic/LLM consumption
- [x] **FMT-02:** Minimal output format for token efficiency
- [x] **FMT-03:** Support for piping and shell integration
